# 常驻屏运维（LCARS 控制台）

本文说明把手机当作打印机旁常驻屏时的几项运维功能。

## 首页摄像头

- 局域网模式下，首页左侧显示打印仓摄像头画面，三维模型移到了待机画面。
- 轻触画面可以放大，再点一下收回。
- 云端模式下拿不到摄像头画面，首页仍显示三维模型。

摄像头协议和取帧方式：

- P1 系列的摄像头在 TLS 6000 端口，每 1–2 秒一帧 JPEG。
- 打印机主控很弱，最多只能同时服务一两个客户端。
- **Node 后端**：同一台打印机只向打印机拉一路流，再分发给所有在看的页面。新加入的页面立刻收到最新一帧。最后一个页面离开 5 秒后断开。
- **Android 壳**：页面本身就是唯一的客户端，所以直接转发。
- 页面不可见或进入待机画面时，摄像头连接会断开。

可以在「设置 → 待机与更新」里关掉首页摄像头。

## 待机画面与背光

第三方应用画不进 LG 的息屏显示（AOD），所以控制台自带一个待机画面：

- **进入**：3 分钟没有触摸，且没有新告警时进入。
- **内容**：
  - 三维模型，以约 12 帧/秒绘制；
  - 时钟；
  - 打印进度、层、剩余时间、温度；
  - 正在执行的 G-code 前后几行。
- **防残影**：整个画面每 90 秒平移一次，最多约 ±14 px。
- **退出**：触摸、在听筒上方挥一下手、出现告警、打印结束，都会退出待机。

G-code 的来源：

- 页面通过 FTPS 下载当前任务的 .3mf，取出其中的 G-code，并按层建立索引。
- 如果打印机上报了当前行号（`mc_print_line_number`），窗口就精确跟随这一行。
- 如果没有上报行号，就显示当前层的内容，并标注「位置为估算」。
- 只有局域网模式能读取 G-code。

背光亮度（通过 Android 壳设置窗口亮度）：

| 状态 | 亮度 |
|---|---|
| 有人操作（5 分钟内触摸过）或有告警 | 跟随系统 |
| 打印中，无人操作 | 50% |
| 待机画面，打印中或刚结束 10 分钟内 | 8% |
| 待机画面，空闲 | 3.5% |
| 空闲熄屏（可选） | 交给系统超时熄屏 |

关于空闲熄屏：

- 打开「空闲时熄屏」后，没有打印任务时由系统的屏幕超时把屏幕关掉，所以要在系统设置里把超时设短一些。
- 熄屏期间 CPU 保持唤醒（手机一直插着电），控制台会继续跟踪打印机。
- 开始打印、出现告警或挥手时，屏幕自动点亮。
- 锁屏方式需要设为「无」或「滑动」，否则会被锁屏界面挡住。

挥手唤醒用的是距离传感器：

- 有效距离只有 3–5 cm，需要在听筒附近挥一下。
- 遮住传感器超过 1.5 秒不算挥手，比如手机正面朝下放置时。

## 网页在线更新

每次构建都会在 `dist/web` 里生成两个文件：

- `version.json`：本次构建的编号，以及更新包的大小和 SHA-256；
- `web.zip`：整套网页。

页面每 5 分钟读一次自己所在服务器上的 `/version.json`。发现编号变了，就在 10 分钟无人操作时自动刷新。

- **Node 后端 / Docker**：重新部署 `dist/web` 即可。
- **Android 壳**：先在「设置 → 待机与更新」里填写更新来源，例如电脑上运行的后端 `http://192.168.1.10:8889`。调试版安装包也可以用 adb 设置（正式版不接受这个参数，因为手机上任何应用都能发出同样的指令）：

  ```powershell
  adb shell am start -n com.bambulab.p1screen/.MainActivity --es webOrigin http://192.168.1.10:8889
  ```

  Android 壳每 15 分钟检查一次更新来源，安装过程如下：

  1. 下载 `web.zip`。
  2. 校验大小和 SHA-256。
  3. 解压到应用私有目录，整体切换。
  4. 新版本从开始加载起 20 秒内没有成功启动（页面没有回报），就自动回退到上一个能用的版本，并且不会再装这个版本。

  新版本还在等待启动确认时，不会安装更新的版本，等下一次检查再装。解压后的总大小超过 256 MB 的更新包会被拒绝。

  更新来源连不上时，继续使用已经装好的版本；如果还没有装过任何版本，就使用安装包内置的版本。来源留空时，恢复使用内置版本。

## 前端报错落盘

页面里未捕获的错误每 5 秒批量上报一次：

- **Node 后端**：写入 `logs/frontend.log`，超过 2 MB 时轮转，可通过 `GET /api/log` 查看。
- **Android 壳**：写入应用私有目录的 `logs/frontend.log`，超过 1 MB 时轮转。在同一局域网的电脑上打开 `http://<手机IP>:8888/api/log` 就能查看。

## 无线调试

手机先用数据线连电脑一次，打开无线 ADB：

```powershell
adb tcpip 5555
```

拔掉数据线后，按手机 IP 连接：

```powershell
adb connect 192.168.1.50:5555
```

之后可以：

- 在电脑 Chrome 打开 `chrome://inspect` 调试 WebView。应用里已开启 WebView 调试。
- 用 [scrcpy](https://github.com/Genymobile/scrcpy) 远程查看和操作屏幕：

  ```powershell
  scrcpy --stay-awake --turn-screen-off
  ```

  这里的 `--turn-screen-off` 只关手机屏幕，不影响电脑上的画面，适合长时间远程操作时保护背光。

Android 13 及以上也可以在开发者选项里打开「无线调试」，配对后用 `adb pair` 和 `adb connect` 连接。

## 编译 Android 壳

- 需要 Android SDK（platform 36、build-tools、platform-tools），在 `android/local.properties` 里写上 `sdk.dir`。
- 仓库里没有发布用的签名文件 `keystore.jks`，所以调试包改用 SDK 自带的调试密钥签名。
- 调试密钥签名的安装包不能覆盖安装正式签名的版本，需要先卸载旧版。

```powershell
cd android; .\gradlew.bat :app:assembleDebug
```
